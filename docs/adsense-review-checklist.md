## 3. 조건부 작업 상태 및 ads.txt 가이드

- **게시자 ID**: 미입력 (가짜 ID 입력 금지 원칙 준수)
- **추후 AdSense 승인 후 ads.txt 설정 방법**:
  1. 구글 애드센스 승인 완료 후 관리자 콘솔에서 게시자 ID(예: `pub-XXXXXXXXXXXXXXXX`) 확인
  2. `public/ads.txt` 파일 생성:
     ```text
     google.com, pub-XXXXXXXXXXXXXXXX, DIRECT, f08c47fec0942fa0
     ```
  3. 배포 후 `https://my-local-info-seongnam.pages.dev/ads.txt` 접속하여 일반 텍스트 형태로 정상 출력되는지 확인
